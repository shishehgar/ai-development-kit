# AIDK Studio

AIDK Studio is the visual engineering workspace for AI Development Kit.

## Purpose

AIDK Studio provides a graphical interface for:

- Creating new software projects
- Registering and analyzing existing projects
- Inspecting repository structure
- Managing Git information
- Running engineering audits
- Generating improvement plans
- Reviewing and applying safe fixes
- Inspecting dependencies and licenses
- Managing stored project data
- Generating engineering reports
- Accessing contextual help from every screen

## Architecture

AIDK Studio must use the existing AIDK Python services as its domain layer.
Business logic must not be duplicated in the frontend or API routes.
